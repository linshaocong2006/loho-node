# LoHo Node 客户端

安卓最新版：[LoHo-Node-1.0.3.apk](LoHo-Node-1.0.3.apk)。Android 8.0 及以上可安装。

1.0.3 关闭管理界面的双指缩放、双击缩放和缩放按钮。沿用原来的包名和签名，可直接覆盖安装；无需卸载，已保存的服务器地址及应用数据会保留。

本次只更新安卓客户端，服务器无需因本次修复重新升级。服务端当前版本为 v10.1.2；iPad 仍通过 Safari 添加到主屏幕使用。

安装包的 SHA256 校验值见仓库根目录的 `SHA256SUMS`。

服务端 v10.1.2 修复 iPad 概览页用户弹窗遮挡，精简手机上下导航并修正客户端头像比例。已安装 Android 1.0.3 的用户升级服务器后，完全退出并重新打开客户端即可，无需重新安装 APK。
