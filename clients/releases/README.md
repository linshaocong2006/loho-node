# LoHo Node 客户端

安卓最新版：[LoHo-Node-1.0.4.apk](LoHo-Node-1.0.4.apk)。Android 8.0 及以上可安装。

1.0.4 在原生触摸分发层拦截双指手势，并保留单指点击和滚动；对实际四个菜单中的嵌入页面和用户弹窗增加手势检查。应用内“账号与设置”显示当前 Android 客户端版本。

沿用原来的包名和签名，可直接覆盖安装，无需卸载，已保存的服务器地址及应用数据保留。

服务端最新版 v10.1.3 统一连接筛选值的字体和字号（14px），并给安卓页面增加手势限制。请同时覆盖安装 Android 1.0.4 和升级服务器。iPad 完全退出并重新打开网页应用即可加载更新。

安装包 SHA256 校验值见仓库根目录的 `SHA256SUMS`。
