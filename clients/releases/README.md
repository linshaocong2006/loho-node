# LoHo Node 客户端

安卓最新版：[LoHo-Node-1.0.6.apk](LoHo-Node-1.0.6.apk)。Android 8.0 及以上可安装。

1.0.6 修复系统安全区重复留白：原生层负责状态栏、屏幕挖孔和底部手势/键盘避让，处理后不再把相同尺寸传给 WebView。沿用双指拦截及概览返回退出功能。

同包名、同签名，可覆盖安装并保留应用数据。服务端最新版 v10.1.8 将安卓上下导航栏收紧为 48px，保留至少 44px 的菜单点击区域；安卓网页不再重复预留原生安全区。iPad/PWA 继续按浏览器安全区布局。

已安装 Android 1.0.6 时，本次只需更新服务器并退出重开客户端。连接页筛选标签与选中值统一为 13px，仅用颜色区分层级。旧版安卓客户端建议先覆盖安装 1.0.6。安装包校验值见仓库根目录 `SHA256SUMS`。

v10.1.7 优化概览分批显示和连接图标刷新，修复历史查询回车、中文输入、用户改名同步和重试筛选丢失，并改善保存与错误恢复反馈。Android 1.0.6 无需重装，网页和 iPad/PWA 同步生效。

v10.1.8 收紧用户配置弹窗，手机二维码默认 176px，短屏进一步调整。UUID 与导入链接默认收起，复制与关闭按钮始终可见，顶部增加关闭入口。Android 1.0.6 无需重装，更新服务器后退出重开客户端。
