# LoHo Node 客户端

安卓最新版：[LoHo-Node-1.0.5.apk](LoHo-Node-1.0.5.apk)。Android 8.0 及以上可安装。

1.0.5 修复返回手势被网页历史接管的问题：弹窗优先关闭，其他菜单回概览，概览页再返回即退出客户端；不再循环回到旧菜单或进入服务器设置。沿用双指拦截。

同包名、同签名，可覆盖安装并保留应用数据。服务端最新版 v10.1.4 将双端筛选值字号从 14px 缩至 13px，字体保持与正文一致；弹窗返回尊重正在保存时的关闭限制。

请同时更新安卓 APK 和服务器。iPad 更新服务器后退出并重新打开网页应用即可。安装包校验值见仓库根目录 `SHA256SUMS`。
